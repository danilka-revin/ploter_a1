# JBD BMS — приложение для Windows и Linux (Python)

Программа для чтения и настройки платы BMS JBD (Jiabaida / Xiaoxiang) по UART.
Рассчитана на батарею **12S 3P LiFePO4 (~40 В)**, номинальная ёмкость — параметр платы.
Интерфейс на PySide6, оформление как в linux_pcb_app (тёмная и светлая тема).

## Что умеет

- **Обзор** — напряжение, ток, направление, заряд (%, Ач), ключи заряда/разряда,
  балансировка, температуры, активные защиты, счётчики срабатываний.
- **Ячейки** — компактная плитка на каждую банку: напряжение, отклонение от среднего,
  полоска заряда, метка балансировки; сводка: минимум, максимум, разброс, сумма.
- **Управление** — включение/выключение заряда и разряда, установка остатка ёмкости,
  сброс счётчиков ошибок, резервная копия настроек в JSON и восстановление
  (сначала список «было → станет»).
- **Настройки** — пороги защит, номинальная ёмкость, токи, температуры, балансировка.
  Значения проверяются по пределам и шагу регистра, проверяется согласованность порогов.
  Запись — только после подтверждения; после записи каждый параметр перечитывается.
- **Журнал** — события подключения и ошибок; история опроса экспортируется в CSV.
- **Обновление** — проверка новых коммитов ветки `main` в GitHub, установка через
  `git merge --ff-only`, при изменении `requirements.txt` — `pip install`, перезапуск.

Прошивка не реализована: протокол загрузки не подтверждён.

## Установка (Windows 10/11)

Установите [Git](https://git-scm.com/download/win) и [Python 3.10+](https://www.python.org/downloads/windows/) (с опцией **Add Python to PATH**), затем:

```powershell
git clone https://github.com/danilka-revin/ploter_a1.git
cd ploter_a1\jbd-bms-py
.\install-windows.cmd
```

Установщик создаст виртуальное окружение и ярлык **JBD BMS Python**. Последующий запуск —
ярлыком или `run-windows.cmd`. Порт платы в Windows имеет имя `COM3`, `COM4` и т. п.
Драйвер USB–UART (CH340, CP210x, FTDI) должен быть установлен.

## Установка (Ubuntu / Debian / Mint)

```bash
git clone https://github.com/danilka-revin/ploter_a1.git
cd ploter_a1/jbd-bms-py
bash install-ubuntu.sh
```

Установщик ставит системные библиотеки Qt, создаёт `.venv`, добавляет пользователя в группу
`dialout` (доступ к `/dev/ttyUSB*`), создаёт ярлык и команду `jbd-bms`.
После добавления в `dialout` нужно выйти из сессии и войти снова.

## Запуск

```bash
./run.sh                 # окно программы
./run.sh --demo          # демо-режим без платы (эмулятор 12S)
./run.sh --port /dev/ttyUSB0   # Linux
run-windows.cmd --port COM3  # Windows
```

Подключение к плате: выберите порт в списке и нажмите «Подключить».
Порт — USB-UART адаптер, 9600 бод, 8N1.

## Обновление

Кнопка «Обновить программу» появляется, когда в `main` есть новые коммиты, затрагивающие
`jbd-bms-py/`. Обновление возможно только в чистом git-клоне, на ветке `main`, без локальных
правок в папке программы. Иначе программа сообщит причину и ничего не изменит.

## Тесты

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q tests
```

Тесты протокола и клиента работают без платы (эмулятор `jbd_bms/fake.py`).
Тест обновления использует локальный bare-репозиторий. GUI-тест пропускается, если Qt не запускается.

## Структура

```
jbd_bms/protocol.py   кадры, разбор данных, регистры, пределы, проверки (без ввода-вывода)
jbd_bms/client.py     обмен с платой, запись в заводском режиме, транспорт UART (pyserial)
jbd_bms/service.py    фоновый опрос, переподключение, история, CSV, очередь команд
jbd_bms/fake.py       эмулятор платы 12S для демо и тестов
jbd_bms/updater.py    обновление из GitHub
jbd_bms/ui/           интерфейс PySide6
tests/                тесты
run.sh                запуск с перезапуском после обновления (код выхода 10)
```

## Ограничения

- Проверено на эмуляторе и тестах, **на реальной плате JBD не проверено**. Перед записью
  настроек сверяйте значения с документацией батареи и платы.
- Команда «сбросить счётчики» сохраняет нули в память платы — как bms-tools; поведение
  на конкретной модели стоит подтвердить.
- Пароль платы: поддерживается ввод 6 символов при записи. Смена пароля не реализована.
- Число ячеек, калибровка, балансировочные тесты и прошивка в приложении не делаются.
