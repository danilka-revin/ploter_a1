# Школьный бот (10ит, Красноярск)

Telegram-бот: расписание класса с учётом замен, погода, курсы ЦБ РФ, новости.

| Команда | Что делает |
|---|---|
| `/today` | расписание на сегодня (если сегодня нет занятий - ближайший учебный день) |
| `/weather` | погода в Красноярске |
| `/rates` | курсы USD, EUR, CNY по ЦБ РФ |
| `/news` | 5 главных новостей |
| `/daily` | всё сразу |
| `/start` / `/stop` | подписаться / отписаться от ежедневной рассылки |

Рассылка приходит каждый день в **07:00** (Красноярск).

## Установка на Ubuntu (одна команда)

```bash
sudo apt install -y git python3 python3-venv
git clone https://github.com/danilka-revin/ploter_a1.git
cd ploter_a1
git checkout arena/c894ce62-ploter-a1
bash school_bot/deploy/install.sh
```

Скрипт:
- создаст виртуальное окружение и установит зависимости;
- спросит токен бота из @BotFather и сохранит его в `school_bot/.env` (файл закрыт для чтения другими пользователями и не попадает в Git);
- включит автозапуск через systemd: бот стартует при входе в систему (а с `linger` - сразу после включения ПК);
- добавит ярлык «Школьный бот» в меню приложений и на рабочий стол.

Если скрипт попросит, выполните один раз: `sudo loginctl enable-linger $USER` - тогда бот запускается даже до входа в систему.

## Ярлык и управление

Ярлык «Школьный бот» на рабочем столе:
- **Школьный бот** - запустить бота;
- **Перезапустить и обновить с GitHub** - подтянуть новую версию и перезапустить;
- **Показать логи**, **Проверить состояние**, **Остановить бота**.

То же из терминала:

```bash
systemctl --user status school-bot      # состояние
systemctl --user restart school-bot     # перезапуск
journalctl --user -u school-bot -f      # логи
```

## Автообновление

При каждом запуске и каждые 30 минут бот делает `git pull` в этом репозитории.
Если на GitHub появился новый коммит, зависимости обновляются и бот перезапускается.
Для этого клон должен отслеживать ветку (`git status` покажет `up to date with 'origin/...'`).
Если в клоне есть свои незакоммиченные правки в файлах проекта, `git pull` может не сработать - тогда в логах будет сообщение.

## Расписание

Данные берутся с `raspisanie.nikasoft.ru` (класс 10ит, id `22811554`):
1. со страницы `check/22811554.html` узнаётся актуальный файл расписания (он меняется при каждом обновлении);
2. из файла читается базовое расписание и замены на даты (`CLASS_EXCHANGE`);
3. уроки, отменённые заменой («F»), скрываются; изменённые отмечаются 🔄;
4. подгруппы выводятся отдельными строками («Группа 1», «1 группа» и т.д.).

Если сайт недоступен, бот использует файл `school_bot/data/schedule.txt` (пример - `schedule.example.txt`).

Проверить расписание из терминала:

```bash
cd school_bot && .venv/bin/python debug_schedule.py
```

Тесты разбора (без сети):

```bash
cd school_bot && .venv/bin/python -m unittest discover -s tests -v
```

## Удаление автозапуска и ярлыков

```bash
bash school_bot/deploy/uninstall.sh
```

## Файлы

- `bot.py` - Telegram-команды и рассылка
- `schedule.py` - загрузка расписания с сайта, кэш, текст для Telegram
- `schedule_parser.py` - разбор данных Ника-Софт (базовое расписание, замены, подгруппы)
- `weather.py` - погода (Open-Meteo, без ключа)
- `rates.py` - курсы ЦБ РФ
- `news.py` - новости (RSS)
- `config.py` - настройки (класс, город, время рассылки)
- `deploy/` - установка, автозапуск, обновление, ярлыки
- `tests/` - проверки разбора расписания на данных вашего класса
