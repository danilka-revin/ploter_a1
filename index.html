💡 SVG — готовый файл для принтера или конвертации в G-код.
G-код генерируется через Python-скрипт convert_svg_to_gcode.py.

📋 Как использовать с Bambu Lab A1

  1. Введи текст домашки в поле слева.
  2. Настрой внешний вид с помощью ползунков (наклон, размер, расстояние, толщина).
  3. По желанию загрузи фото своего почерка для сравнения.
  4. Нажми «Скачать SVG» или «Скачать G-код».
  5. Для G-кода: запусти python3 convert_svg_to_gcode.py output.svg.
  6. Загрузи G-код в принтер с ручкой и печатай на бумаге.
