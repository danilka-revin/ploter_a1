# JBD BMS Manager

Приложение для диагностики и настройки аккумуляторных сборок с BMS **JBD / Jiabaida / Xiaoxiang / Overkill Solar** через USB–UART. Работает в Windows 10/11 и Ubuntu/Debian.

![JBD BMS](jbd-bms-app/public/logo.png)

## Возможности

Одна большая панель на весь экран вместо набора страниц: ничего не нужно прокручивать, все плитки живые.

- **акцент на банки в аккумуляторе** — крупная сводка по банкам (мин/сред/макс, разброс Δ, сумма, балансировка) и интерактивная карточка каждой банки `#1…#N` с напряжением в В и мВ, отклонением от среднего и подсветкой на графике;
- **графики в едином дизайне** за 2/5/15/60 минут: динамика напряжений банок, разброс банок и заряд, профиль по банкам `#1…#N`, напряжение и ток, мощность, температуры датчиков;
- **несколько плат BMS одновременно** — каждая плата на своём UART-адаптере, опрос параллельно, итоги по парку;
- напряжение сборки и каждой банки, ток, мощность, SOC, остаток в Ач, циклы, температуры по датчикам, 13 защит и счётчики их срабатываний;
- **настройка и управление по UART** без сырых регистров в интерфейсе: пороги защит банок и сборки, токи, температуры, ёмкость, таблица SOC, задержки срабатывания и возврата, маски функций и датчиков, ключи заряда/разряда, остаток ёмкости, балансировка, сбросы;
- отчёт и выгрузка CSV для Excel/Google Sheets;
- печать сводки на TTL-чековом принтере (простой текст / ESC/POS / AlexGyver, 58/80 мм) в трёх видах — **короткий, средний и полный** (вид сохраняется и печатается в шапке чека строкой `Report`): чек на английском языке символами ASCII — с транслитерацией русских подписей, с предпросмотром на экране; если принтер печатает мусор вместо текста, скорость UART подбирается сама («Найти скорость (авто)» перебирает 9600/19200/… и 8N1/8E1/7E1 по ответу принтера) или печатью блоков на всех скоростях;
- резервное копирование и восстановление настроек, демо-режим без плат (1–6 эмуляторов);
- проверка Intel HEX (запись прошивки отключена до подтверждения протокола JBD);
- обновление из ветки `main` на GitHub.

## Быстрый запуск в Windows

Потребуются **Windows 10/11 x64**, [Git](https://git-scm.com/download/win) и [Node.js 20+ LTS](https://nodejs.org/).

```powershell
git clone https://github.com/danilka-revin/ploter_a1.git
cd ploter_a1\jbd-bms-app
.\install-windows.cmd
```

Установщик загрузит зависимости, соберёт приложение и создаст ярлык **JBD BMS** на рабочем столе. Для последующих запусков используйте ярлык или `run-windows.cmd`. Откроется <http://127.0.0.1:8585>.

Если PowerShell запрещает сценарии, запускайте именно `.cmd` — он применяет обход политики только к этому запуску.

## Подключение BMS

Используйте USB–UART адаптер CP2102, CH340 или FTDI:

| USB–UART | BMS |
|---|---|
| RX | TX |
| TX | RX |
| GND | GND |

UART: **9600 бод, 8N1**, без управления потоком. Уровень логики большинства плат — **3,3 В**; проверьте документацию своей модели, поскольку 5 В может повредить BMS. В Windows установите драйвер адаптера, если порт `COM` не появился в диспетчере устройств. В приложении нажмите «Найти батарею» или выберите `COM3`, `COM4` и т. п. либо «Демо-режим». Как понять порт вручную — см. [`jbd-bms-app/docs/kak-najti-port.md`](jbd-bms-app/docs/kak-najti-port.md).

> **Безопасность:** неверные пороги могут отключить защиту аккумулятора. Перед записью сохраните резервную копию и сверьте значения с документацией платы и химией ячеек.

## Ubuntu / Debian

```bash
git clone https://github.com/danilka-revin/ploter_a1.git
cd ploter_a1/jbd-bms-app
bash install-ubuntu.sh
```

После установки заново войдите в систему, чтобы применилось членство в группе `dialout`. Запуск: `jbd-bms` или `bash run.sh`.

## Разработка и тесты

```bash
cd jbd-bms-app
npm install
npm run dev
npm run build
npm test
```

Подробные инструкции, описание экранов, протокола и ограничений находятся в [`jbd-bms-app/README.md`](jbd-bms-app/README.md). Инструкции для Python-клиента — в [`jbd-bms-py/README.md`](jbd-bms-py/README.md).

## Лицензия и статус

Проект находится в разработке. Обмен и запись настроек покрыты автоматическими тестами, но работу с конкретной моделью BMS необходимо проверять на безопасных значениях. Функция записи прошивки намеренно отключена: открытый подтверждённый протокол загрузчика JBD отсутствует.
