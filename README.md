# Почерк A1 — Плоттер для домашки по русскому

Это веб-приложение для принтера **Bambu Lab A1** с креплением для ручки.
Оно позволяет написать текст домашки, настроить внешний вид (почерк) и получить файл для печати на бумаге.

## Возможности

- ✏️ Ручной ввод текста домашки
- 📷 Загрузка образца почерка для сравнения
- 🎨 Настройка стиля: наклон, размер букв, расстояние, толщина линии, цвет чернил
- 👁️ Предпросмотр на «бумажном» фоне
- ⬇ Экспорт в SVG (универсальный формат)
- ⬇ Экспорт в G-код для ручного плоттера (через Python-скрипт)

## Быстрый старт

1. Открой `index.html` в браузере.
2. Введи текст домашки.
3. Настрой внешний вид с помощью ползунков слева.
4. Нажми «Скачать SVG» или «Скачать G-код».

## Конвертация SVG → G-код

```bash
python3 convert_svg_to_gcode.py output.svg my_homework.gcode
```

Затем загрузи `my_homework.gcode` в принтер Bambu Lab A1 с ручкой.

## Технологии

- HTML5 + CSS3 + JavaScript (без сборки)
- Google Fonts (Caveat, Marck Script, Lobster, Pacifico)
- Python 3 для конвертации SVG в G-код

## Примечание

Полная автоматическая репликация почерка по фото требует нейросетевых моделей (например, Handwriting.io или кастомных GAN). В этой версии используется выбор готовых рукописных шрифтов + ручная настройка параметров для имитации вашего почерка. Для более точного копирования загрузи фото почерка — оно отображается в предпросмотре для сравнения.
